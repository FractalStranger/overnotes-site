Overnotes

Overnotes is a small tool for bands and music producers. Members record or upload takes, comment on exact seconds of the waveform, reply in threads and organise recordings into projects and folders.

It is a private app for a band and its friends. Access is by invitation, and each project's recordings can be stored in the project owner's own Google Drive.

Google Drive

If you create a project, Overnotes asks for permission to create files in your Google Drive. It uses the limited drive.file permission, so it can only see and manage the files it creates itself, in an overnotes folder. It cannot read anything else in your Drive.
